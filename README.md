# APL121 — Голч дүн (GPA)

**Сэдэв №9.** Энэ багц нь Flowgorithm-ийн `.fprg` схем, C хувилбар, псевдокод, тестийн жишээг агуулна.

## Ажиллуулах

1. Flowgorithm програм нээнэ.
2. `quest.fprg` файлыг `File → Open` цэсээр нээнэ.
3. `Run` дарж ажиллуулна.
4. C хувилбар: `gcc main.c -o gpa` гэж компайл хийгээд `./gpa` (Windows дээр `gpa.exe`) командыг ажиллуулна.

## Тогтоосон дүрэм

- Хичээлийн тоо: 5–10.
- Оноо: 0–100; үүнээс гадуур утга оруулбал дахин асууна.
- Кредит: 1–6 бүхэл тоо; хүрээнээс гадуур бол дахин асууна.
- Хичээлийн нэрийг зайгүй нэг үгээр оруулна (жишээ нь `Math`, `Programming`).
- A=4, B=3, C=2, D=1, F=0 grade point.
- Жигнэсэн голч: `Σ(grade point × credit) / Σ(credit)`.
- GPA ангилал: 3.5–4.0 “Маш сайн”; 3.0–3.5-аас бага “Сайн”; 2.0–3.0-аас бага “Дунд”; бусад нь “Сайжруулах шаардлагатай”.
- Шилдэг 3 хичээлийг оноогоор буурах дарааллаар эрэмбэлнэ.

## Файлууд

- `quest.fprg` — Flowgorithm дээр нээж, ажиллуулах схем.
- `flowchart.png` — алгоритмын ерөнхий урсгалын зураг. Flowgorithm дээр нээсний дараа `Tools → Export to an Image File` ашиглан програм дотроос экспортолсон зургаар сольж болно.
- `main.c` — C хэлний хувилбар.
- `pseudocode.md` — псевдокод.
- `tests.md` — тестийн кейсүүд.
